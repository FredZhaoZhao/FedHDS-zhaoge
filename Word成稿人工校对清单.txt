Word 成稿人工校对清单
====================

说明
----
1. 已自动核对到：Markdown 的章节骨架已完整同步到两份 Word 成稿。
2. 目前主要剩余的是版式、图表、目录、编号、引用和少量措辞层面的人工检查。
3. 下面按优先级列出，建议从上到下逐项勾选。


一、必须先查
----------
[ ] 1. 更新目录域
    - 打开 Word 后执行“更新域/更新整个目录”。
    - 确认目录页码与正文一致。

[ ] 2. 检查标题层级
    - 一级标题、二级标题、三级标题是否和 Markdown 对齐。
    - 特别看第 3 章方法、第 5 章结果、第 6 章局限性、第 7 章结论。

[ ] 3. 检查中英文成稿是否内容一致
    - 英文版和中文版的章节顺序、结论边界、局限性表述是否对应。
    - 不要求逐字一致，但要求意思一致。

[ ] 4. 检查摘要和关键词
    - 摘要是否完整。
    - 关键词数量是否一致。
    - 是否有明显漏句、换行错误或乱码。


二、重点检查正文
--------------
[ ] 5. 检查贡献列表
    - 是否还残留“训练底座是本文贡献”之类的表述。
    - 是否统一写成：FedHDS 是采用的训练底座，本文贡献在训练后遗忘模块。

[ ] 6. 检查方法章第 3 章
    - 公式编号是否连续。
    - 变量说明是否完整。
    - 是否有公式被拆坏、换行错位或上下标显示异常。
    - 重点看 `direction probing`、`global guard`、`forget-loss guard` 三段。

[ ] 7. 检查实验设计第 4 章
    - 数据集、模型、客户端数、采样比例、遗忘客户端等配置是否和 Markdown 完全一致。
    - retrain baseline 相关说明是否保留了“尚未纳入主表”的口径。

[ ] 8. 检查结果第 5 章
    - 表 1 到表 10 的标题是否都在。
    - 图 1 到图 7 的标题是否都在。
    - 结果叙事是否仍按“问题 -> 证据 -> 边界”展开。
    - 是否还保留“retained-set 全面优于 forget-batch”这种过强说法。

[ ] 9. 检查局限性和结论
    - 是否明确承认：
      单数据集、固定 forget client、seed-sensitive、retrain baseline 未并入主表、主要是 loss-based 指标。
    - 结论是否仍然克制，没有夸成“所有设置下最强算法”。


三、图表与公式
------------
[ ] 10. 检查图
    - 图片是否全部显示出来。
    - 图注是否和正文引用一致。
    - 图和图注是否没有跑到别页去。

[ ] 11. 检查表
    - 表头是否没有被挤乱。
    - 表格列是否对齐。
    - 长表是否有内容被截断或换页丢行。

[ ] 12. 检查公式
    - 行间公式是否居中。
    - 上下标、希腊字母、负号是否显示正确。
    - 公式后面的变量说明是否完整保留。


四、引用与格式
-------------
[ ] 13. 检查参考文献
    - 文末参考文献条目是否完整。
    - 文中 `[1]`、`[2]` 这类引用标号是否没有错位。

[ ] 14. 检查字体和段落
    - 中文、英文、公式附近是否有异常字体。
    - 是否有明显多余空行。
    - 是否有段落被切成怪异的短行。

[ ] 15. 检查英文/中文术语统一
    - FedHDS / forget-batch / retained-set / guard / retrain baseline 等术语是否一致。
    - 中文版和英文版术语不要互相漂移。


五、快速抽查顺序
--------------
1. 目录
2. 摘要和关键词
3. 第 3 章方法
4. 第 5 章结果
5. 局限性和结论
6. 图表与参考文献
